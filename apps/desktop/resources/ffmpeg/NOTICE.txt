OpenMovie FFmpeg Sidecar
========================

OpenMovie source releases do not contain FFmpeg binaries. Official Windows and macOS installers
bundle FFmpeg and FFprobe as separate command-line programs under this directory. OpenMovie invokes
them through a process boundary and remains licensed under 0BSD.

macOS builds use FFmpeg 9.0.1 source from:
https://ffmpeg.org/releases/ffmpeg-9.0.1.tar.xz
SHA-256: cf38e0e28c7e5605942c4a77755349b0145804a397af37eb1fb4c77cb237f635

Windows x64 builds use the pinned BtbN LGPL static build of FFmpeg 9.0.1-6-g9d4ca21220:
https://github.com/BtbN/FFmpeg-Builds/releases/tag/autobuild-2026-08-20-13-45
Asset: ffmpeg-n9.0.1-6-g9d4ca21220-win64-lgpl-9.0.zip
SHA-256: ccaa910db95451121482a5ebcb8c682123cb4f8a5bd5170fde4a814d7b437772
Build scripts: https://github.com/BtbN/FFmpeg-Builds/tree/48576f1

These release builds use the LGPL feature set and do not enable GPL or nonfree components. The
installer includes the applicable FFmpeg license files beside this notice. Corresponding source is
available at the URLs above. Users may replace the Sidecar with a compatible FFmpeg/FFprobe build by
setting OPENMOVIE_FFMPEG_PATH and OPENMOVIE_FFPROBE_PATH before launching OpenMovie.
